- ویرایش و افزودن تمرین‌های ذهنی

- ویرایش راهنمای حرکات تمرینی
- سه موسیقی آفلاین آرام/تمرکز/تمرین با پخش تکرارشونده
- رنگ‌بندی جداگانه: ذهنیت بنفش، تمرین طلایی، تغذیه سبز، تقویم آبی
- ثبت ست، تکرار، وزن و تایمر
- تقویم ۹۰ روزه و ثبت وزن
